# Development

Enter the project shell from the repository root:

```sh
nix develop
```

It provides Git/search tools, Neovim, Lua tooling, `mpv`, `socat`, Python, and `jq` for development and testing. Leave it with `exit` or `Ctrl-D`.

Find the phased implementation plan at `./docs/codex-implementation-stint.md` to understand what you're supposed to be doing. When the user says "continue", carry on from the next commit in the plan. When you've done one of the commits, check it off on the list.
